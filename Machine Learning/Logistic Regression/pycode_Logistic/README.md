# pycode_Logistic

This folder has the Python scripts for logistic regression.

Each file is small and focused on one part of the topic.

## Files

| File | Why it exists |
|---|---|
| `01_sigmoid.py` | Sigmoid function example |
| `02_logistic_regression.py` | Core logistic regression implementation |
| `03_batch_gd.py` | Batch gradient descent example |
| `04_sgd.py` | Stochastic gradient descent example |
| `05_minibatch_gd.py` | Mini-batch gradient descent example |
| `06_metrics.py` | Classification metrics example |
| `07_regularization.py` | Regularization example |
| `08_demo.py` | Full logistic regression demo |

## How it works

The numbering shows the order of the learning path. It starts with the sigmoid function and moves into the model, optimization, metrics, regularization, and a final demo.
