# plots

This folder stores the PNG plots for the decision tree material.

They are here to show what the scripts are doing and to make the docs easier to follow.

## Files

| File | Why it exists |
|---|---|
| `01_impurity_gini_entropy.png` | Gini impurity and entropy as class proportions change |
| `02_best_split_regression.png` | Candidate regression split errors and the best piecewise fit |
| `03_best_split_classification.png` | Weighted Gini of each classification split |
| `04_regression_tree.png` | Piecewise-constant prediction of the regression tree |
| `05_classification_regions.png` | Axis-aligned decision regions of the classifier |
| `06_depth_overfitting.png` | Train/test error vs. depth; shallow vs. deep fits |
| `07_sklearn_comparison.png` | — (script `07` prints results; no saved plot) |
| `08_demo.png` | — (script `08` prints results; no saved plot) |

## Notes

- These are generated images only.
- They are created by running the scripts in `pycode_DecisionTrees` from the module folder.
- There are no notebooks or raw datasets in this folder.
