# Decision Trees

This folder has the decision tree part of the repo.

It has three things:

- a markdown doc that explains the topic
- Python scripts that show the implementation
- plot images that match the examples in the scripts and docs

## Contents

| Folder / File | Why it exists |
|---|---|
| [`docs/`](./docs/README.md) | Written explanation for the decision tree work |
| [`pycode_DecisionTrees/`](./pycode_DecisionTrees/README.md) | Python scripts for the decision tree examples |
| [`plots/`](./plots/README.md) | Saved figures used in the decision tree material |

## Current progress

- The main documentation is already written.
- There are 8 Python scripts in `pycode_DecisionTrees`.
- There are 6 PNG plots in `plots`.
- The from-scratch trees are checked against scikit-learn in `07_sklearn_comparison.py`.
