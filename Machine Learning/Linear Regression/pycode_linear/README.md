# pycode_linear

This folder has the Python scripts for linear regression.

Each file is small and focused on one topic.

## Files

| File | Why it exists |
|---|---|
| `01_simple_linear.py` | Simple linear regression example |
| `02_multiple_linear.py` | Multiple linear regression example |
| `03_batch_gd.py` | Batch gradient descent example |
| `04_sgd.py` | Stochastic gradient descent example |
| `05_minibatch_gd.py` | Mini-batch gradient descent example |
| `06_diagnostics.py` | Regression diagnostics example |
| `07_vif_multicollinearity.py` | VIF and multicollinearity example |
| `08_assumptions.py` | Checks for linear regression assumptions |
| `09_learning_curves.py` | Learning curve example |
| `10_housing_demo.py` | Housing demo script |

## How it works

The numbering shows the order of the learning path. It starts with basic regression and moves into optimization, checks, and a demo.
