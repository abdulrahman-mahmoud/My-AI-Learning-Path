# Linear Regression

This folder has the linear regression part of the repo.

It has three things:

- a markdown doc that explains the topic
- Python scripts that show the implementation
- plot images that match the examples in the scripts and docs

## Contents

| Folder / File | Why it exists |
|---|---|
| [`EXPALINTION/`](./EXPALINTION/README.md) | Written explanation for the linear regression work |
| [`pycode_linear/`](./pycode_linear/README.md) | Python scripts for the linear regression examples |
| [`plots/`](./plots/README.md) | Saved figures used in the linear regression material |

## Current progress

- The main documentation is already written.
- There are 10 Python scripts in `pycode_linear`.
- There are 18 PNG plots in `plots`.
